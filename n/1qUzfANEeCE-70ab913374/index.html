    • '생생 반응' 채널: 구독자 2만 명인데 조회수 221만, 98만, 83만 회로 운영자는 "노다지 채널"이라고 부릅니다.

[3단계] 썸네일 각 잡기, 10% 법칙 (29:47)

  • 윤여정은 의상, 만난 사람 등 소식이 많았지만 '윤여정이 보여 준 한국인만의 습성'으로 각을 잡아 20만 회가 나왔다고 합니다.

  • 운영자는 이 부분이 가장 어렵고 해 보면서 실력이 는다고 말합니다. 자세한 방법은 다음 영상에서 다루겠다며 넘어갑니다.

[4단계] '도사 AI 프롬프트'로 대본 만들기 (31:55)

  • 원본 영상의 '설명'을 펼쳐 맨 아래 '스크립트 표시' 버튼을 누르면 전체 스크립트가 뜹니다. 영어든 한국어든 상관없으니 복사합니다.

    • 원본 링크
    • 소재 설명: 원본 설명란에 적힌 출신 국가를 Google 번역으로 확인해 "설악산에 오른 호주 커플"처럼 적습니다.

단계별 방법

① 채널명·로고 만들기

  1. ChatGPT에 입력합니다.
    나 해외 반응 유튜브 시작하려고 해. 채널명 20개 추천해 줘.
  2. 한눈에 해외 반응 채널로 보이는 이름 하나를 고릅니다(예: 외국인의 눈).
  3. 이미지 생성을 선택해 입력합니다.
    유튜브 채널 로고를 만들려고 해. 외국인의 눈이라는 채널이야. 한국 문화를 경험한 외국인의 반응을 소개하는 채널이야. 알맞게 만들어 줘.
  4. 결과 이미지를 다운로드합니다.

② 채널 개설 + 알고리즘 길들이기

  1. 크롬 오른쪽 위 점 세 개(⋮) → 새 시크릿 창을 엽니다.
  2. YouTube에 로그인 → 채널 만들기에서 채널명을 입력하고, 핸들은 그대로 두거나 수정하고, 로고를 사진으로 올린 뒤 채널을 만듭니다.
  3. 검색창에 해외 반응 또는 외국인 반응을 입력하고, 오른쪽 위 필터 → 인기도로 정렬합니다.
  4. 한국 문화를 경험한 외국인 반응 영상 가운데 구독자는 적은데(2만~3만 명 수준) 조회수가 높은(100만 회 안팎) 채널을 찾아 구독합니다.
  5. 같은 방법으로 30~50개 채널을 구독합니다.
  6. 홈 화면에서 조회수 10만 회 이상이고 구독자는 적은 채널의 영상을 고릅니다.

③ 원본 찾기

  1. 고른 영상의 왼쪽 위 화면이나 설명란 더보기에서 원본 출처를 찾습니다.
  2. 출처 이름을 복사해 YouTube에서 검색하고 원본 영상과 채널을 찾습니다.
  3. 원본 설명란에 적힌 출신 국가 등을 Google 번역으로 확인합니다.

④ 대본 만들기

  1. 원본 영상의 설명 → 맨 아래 스크립트 표시 → 전체 스크립트를 복사합니다.
  2. Claude에 프롬프트, 스크립트, 원본 링크, 소재 설명(예: 설악산에 오른 호주 커플)을 넣고 모델은 Opus로 실행합니다. 도사 프롬프트 전문은 영상에서 공개되지 않았습니다.
  3. 결과에서 제목, 후킹 구간 타임코드, 후킹 자막, 나레이션을 확인합니다.

⑤ 재료 3가지 모으기

  1. Vrew → 새로 만들기 → AI 목소리로 시작하기 → 나레이션 대본을 붙여 넣습니다.
  2. 목소리를 골라 미리 들어 봅니다(영상에서는 '제피로스'). → 확인 → 생성 결과를 들어 봅니다.
  3. 오른쪽 위 내보내기 → 오디오: 모든 클립, MP3로 저장합니다(예: 설악산 외국인 반응 테스트).
  4. 내보내기 → 자막 파일: 한국어로 설정해 저장합니다.
  5. 4K Video Downloader에서 원본 링크를 복사한 뒤 링크 붙여넣기 → 다운로드합니다.
  6. Pexels에서 동영상으로 바꾸고 나레이션 문장의 키워드(예: 설악산, 단풍)로 검색해 다운로드합니다.

⑥ CapCut 편집

  1. + 프로젝트 만들기를 누르고 원본 영상을 타임라인에 끌어다 놓습니다.
  2. 타임라인 오른쪽 줌 조절로 구간을 찾고, 후킹 시작점(예: 16초)과 끝점(예: 26초)에서 B 키를 눌러 자릅니다. 필요 없는 앞부분은 지웁니다.
  3. 후킹 구간 뒤에 Vrew에서 받은 MP3와 자막 파일을 넣습니다. 싱크가 맞게 들어갑니다.
  4. 후킹 구간 자막: 위쪽 텍스트 → 기본 텍스트를 원본 영상 위로 끌어다 놓고 길이를 맞춥니다. 오른쪽 위 입력란에 대본의 자막을 붙여 넣습니다.
  5. 자막 꾸미기: 크기를 줄이고 3문장으로 나눈 뒤, 아래쪽 노란색 스타일 버튼을 누르고 획을 두껍게 하고 위치를 조정합니다.
  6. 나레이션 문장마다 Pexels 배경 영상을 넣고 자막 길이에 맞춥니다.
  7. 내보내기 구간 지정: 시작 지점에서 I 키(인포인트), 끝 지점에서 O 키(아웃포인트, 자막에는 '5'로 표기)를 누릅니다. → 오른쪽 위 내보내기를 누릅니다.
  8. 썸네일을 만들어 업로드합니다. 썸네일 제작 방법은 영상에서 생략됐습니다.

⑦ 48시간 점검

  1. YouTube 스튜디오 → 해당 영상의 분석 아이콘 → 조회수 그래프가 계속 오르는지 봅니다.
  2. 도달 범위 탭에서 노출 클릭률을 확인합니다. 10% 이상이면 그대로, 8~10%면 관찰, 8% 미만이면 썸네일을 교체합니다.
  3. 참여도 탭에서 평균 시청 시간을 확인합니다.

생각해볼 점

  • 저작권과 수익 정책 위험: 이 방식은 남의 원본 영상을 내려받아 일부를 그대로 씁니다. 배경 영상을 넣으면 창작물로 인정된다는 것은 운영자의 주장일 뿐입니다. 원작자의 저작권 신고나 유튜브의 '재사용 콘텐츠' 정책에 따라 수익 창출이 거부될 수 있으니, 유튜브 공식 정책과 원작자 허락 여부를 따로 확인하는 것이 안전하다고 봅니다(제 의견). 영상 속 4K Video Downloader로 유튜브 영상을 내려받는 것도 유튜브 약관과 부딪칠 수 있습니다.
  • 수익 사례의 대표성: 증빙 서류는 운영자 본인의 성공을 보여 줄 뿐입니다. 같은 방법을 따라 한 사람이 평균적으로 얼마를 버는지는 피자집 사례 하나뿐입니다. 2021년 윤여정·손흥민 시기의 결과가 지금도 똑같이 나온다는 보장도 없습니다. 영상 속 최근 사례(27만 회에 약 23만 원)는 초기보다 단가가 낮아 보입니다.
  • 홍보 구조: 영상 후반은 유료로 이어질 가능성이 있는 AI 프로그램과 무료 강의로 연결됩니다. 핵심 도구인 '도사 프롬프트'도 전문은 공개되지 않았습니다. "유료 강의 내용을 다 푼다"는 말과 실제 공개 범위 사이에 차이가 있다는 점을 감안해 보세요.
